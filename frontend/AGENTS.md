# Frontend UI

Use the component reference in [src/lib/ui/README.md](src/lib/ui/README.md) and complete [composition recipes](src/lib/ui/COMPOSITION.md) before adding UI. The runnable reference is `/design-system`; its behavioral tests are in `tests/design-system.spec.ts`. Import components and types from `src/lib/ui/index.ts` through the appropriate relative path, and load the single public `src/lib/ui/styles.css` entry in the root layout.
